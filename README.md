# NetGraph

대역(서브넷)을 먼저 정의하는 한국어 네트워크 구성도 편집기. React + TypeScript + Vite 기반이며 서버 없이 브라우저에서 편집합니다.

## 실행

Node.js 20.19+ 또는 22.12+가 필요합니다. 검증 환경: Node 25.8.0.

```sh
npm ci
npm run dev
```

터미널에 표시된 로컬 주소를 브라우저로 여세요.

```sh
npm run test   # IPv4 / CSV / 배치 / 탭 이름 / 실행 취소 회귀 테스트
npm run lint
npm run build  # dist/ 정적 배포 산출물
npm run preview
```

`dist/`는 정적 웹 서버로 제공합니다. HTML 파일을 직접 여는 file:// 실행 방식이 아닙니다.

## 배포

- 서비스 주소: https://rebugui.github.io/netgraph/
- `main`에 푸시하면 GitHub Actions가 테스트·린트·빌드를 실행한 뒤 GitHub Pages에 배포합니다. Pull Request에서는 검증만 실행합니다.
- Vite의 상대 경로 빌드를 사용하므로 `dist/`를 루트 또는 하위 경로에 배포할 수 있습니다.
- 공개 저장소에는 애플리케이션 코드와 합성 예시만 포함됩니다. 편집한 구성도는 브라우저에만 저장되며 GitHub에 업로드되지 않습니다.
- 로컬 실행 주소와 배포 주소는 저장 공간이 다릅니다. 옮기려면 기존 화면에서 **JSON 백업 저장**, 새 주소에서 **JSON 불러오기**를 사용하세요.

`examples/security-all-devices.json`은 17종 장비·보안 장비·이중화 링크를 포함한 합성 예시입니다. JSON 불러오기는 현재 프로젝트를 교체하므로 먼저 백업하세요.

## 사용 순서

1. 기본 골격 또는 빈 캔버스를 선택합니다.
2. 왼쪽 **대역**에서 이름, VLAN, CIDR, 게이트웨이를 입력합니다. 가용 호스트 범위는 입력 즉시 계산됩니다.
3. **장비** 폼에서 소속 대역을 선택하거나 팔레트의 장비를 캔버스로 드래그합니다.
4. 장비 연결점을 드래그해 링크를 만듭니다. 장비와 대역을 직접 연결할 수도 있습니다.
5. 선택 정보에서 속도, VLAN 태그, VPN 터널, 이중화를 편집합니다. 폼 편집 후 **변경 적용**을 누릅니다.
6. **문서 정보**에서 작성자, 검토자, 버전, 변경이력을 기록하고 내보냅니다.

장비 위치는 드래그 종료 또는 선택 후 방향키 이동 시 프로젝트 좌표로 저장됩니다. 여러 장비를 함께 드래그하면 모두 저장되며 실행 취소도 한 번에 적용됩니다. 세그먼트 내부 장비는 부모 상대좌표를 사용하고 부모 범위 안에서 이동합니다. **자동 배치**는 드래그 조정을 초기화합니다. 새 미소속 장비와 대역은 기존 장비·대역 사이 40px 이상의 간격을 찾아 배치합니다. Delete/Backspace 또는 선택 정보의 삭제 버튼으로 항목을 삭제합니다. 대역을 삭제하면 소속 장비는 위치를 유지하며 미소속으로 전환됩니다.

탭의 **＋**로 새 장을 추가하고, 더블클릭으로 이름/구분을 변경하며, 우클릭으로 복제합니다. 휴대폰 화면에서는 **현재 장 작업**에서 이름·구분 변경과 복제에 접근합니다. 자동 생성 이름과 복사 이름은 기존 이름과 겹치지 않습니다. 수동으로 지정하는 이름은 중복을 허용합니다. 마지막 한 장은 삭제할 수 없습니다.

900px 이하 화면에서는 **도면 / 목록·추가 / 속성·검토**로 기존 화면을 전환하고 상단 **메뉴**에서 문서 정보·가져오기·출력·백업에 접근합니다. 새 모바일 전용 편집 제스처를 제공하는 방식은 아닙니다. 패널을 옮겨도 미적용 폼 내용은 유지되며, 프로젝트 작업을 되돌리거나 장을 바꾸면 기존 초안 갱신 규칙이 적용됩니다.

## 저장 및 백업

- HTTPS 또는 localhost에서 Web Locks를 지원하는 브라우저는 localStorage의 `netgraph-project-v1`에 저장 순서대로 자동 저장됩니다. 구버전 탭과 동시에 편집하지 마세요. 두 개의 업데이트된 탭이 같은 저장 내용을 고치면 오래된 탭의 저장을 중지하고 JSON 백업·새로고침을 안내합니다.
- 브라우저/프로필/접속 주소가 다르면 저장 공간도 다릅니다. 사이트 데이터를 삭제하면 프로젝트도 삭제됩니다.
- 저장 중에는 완료로 표시하지 않습니다. 저장 실패·충돌·Web Locks 미지원 또는 저장소 접근 불가 상태에서는 현재 편집 내용을 **JSON 백업**으로 내려받으세요. 미지원 브라우저는 기존 프로젝트를 읽고 메모리에서 편집할 수 있지만 자동 저장은 하지 않습니다. 브라우저 종료 경고는 특히 모바일에서 항상 실행되지 않을 수 있습니다.
- 손상된 저장 데이터는 덮어쓰지 않고 원문 그대로 다운로드할 수 있습니다. 확인 후 빈 프로젝트로 시작해도 그 사이 다른 탭이 데이터를 바꿨으면 원본을 덮어쓰지 않습니다.
- 프로젝트는 브라우저에 **평문**으로 저장됩니다. 비밀번호나 실제 네트워크 접속 비밀을 넣지 마세요.
- **JSON 백업 저장**을 정기적으로 사용하세요. JSON에는 메타데이터, 변경이력, 전체 장, 위치, 링크가 포함됩니다.
- **JSON 불러오기**는 schema 1과 데이터 구조를 검증한 뒤 현재 프로젝트를 교체합니다.
- **⌘/Ctrl+Z**: 실행 취소. **⌘/Ctrl+Y** 또는 **⌘/Ctrl+Shift+Z**: 다시 실행.
- 최근 100개 편집 작업을 현재 세션에서 되돌릴 수 있습니다. 드래그, 삭제, 자동 배치, CSV 반영, 문서 정보, 탭 편집, 프로젝트 초기화/복원이 포함됩니다. 탭 전환 자체는 이력에 쌓이지 않습니다.
- 실행 취소 후 새 편집을 하면 다시 실행 이력은 삭제됩니다. 되돌린 결과도 자동 저장되지만, 실행 취소 이력은 새로고침하면 초기화됩니다.
- 입력칸에서는 브라우저의 텍스트 실행 취소를 사용합니다. 열린 대화상자에서는 프로젝트 실행 취소 단축키를 처리하지 않습니다.
- 서버 동기화와 협업은 제공하지 않습니다.

## IP와 CSV

IPv4만 계산·검증합니다. IPv6는 `/64` 같은 접미사를 포함한 원문 그대로 저장할 수 있지만 지원 안내를 표시하며 IPv4 검증에서 제외합니다. /31은 호스트 2개, /32는 1개입니다. 중복 IP, 대역 밖 IP, 예약 주소, CIDR 중첩, 게이트웨이 오류를 장 단위로 표시합니다.

CSV/TSV 또는 엑셀 표를 붙여넣을 수 있습니다. **입력 양식 내려받기**로 예시를 받으세요. IP의 `/24` 접미사와 점선 마스크를 지원합니다. 잘못된 행은 미리보기에 제외로 표시되고, 알 수 없는 유형은 사용자 정의로 처리됩니다. 대역 이름이 있으면 이름으로 묶고, 이름이 없으면 CIDR로 묶습니다. 새로운 이름을 명시하면 기존 대역과 CIDR이 같아도 별도 대역으로 생성합니다. **반영 시 현재 장의 기존 장비와 대역도 자동 재배치되므로 수동 배치가 바뀝니다.** 기존 항목이 있으면 확인을 받은 뒤 적용하고, 취소하면 도면과 미리보기는 그대로 유지됩니다.

## 출력

- **PPTX 현재/전체 장**: 편집 가능한 도형·텍스트, 타이틀 블록, 범례, 마지막 변경이력 표. 긴 이력은 다음 슬라이드로 이어집니다.
- **PNG**: 현재 장 전체, 흰 배경, 2배 픽셀 해상도.
- **SVG**: 현재 장 전체. HTML 라벨을 포함하는 foreignObject 기반이므로 지원하는 SVG 뷰어/브라우저가 필요합니다.
- **PDF**: A3 가로, 장마다 한 페이지. 이미지 기반입니다.

이미지/PDF는 화면 밖에 동일 장면을 렌더링하므로 현재 확대/이동 상태와 관계없이 타이틀 블록·범례까지 포함하며 활성 탭을 변경하지 않습니다. 폰트와 이모지 모양은 OS 및 PowerPoint 환경에 따라 달라질 수 있습니다.

## 구현 및 검증

- `src/lib/ip.ts`: IPv4 uint32 계산
- `src/lib/deviceTypes.ts`: 캔버스/PPTX 공유 장비 스펙
- `src/lib/layout.ts`: 계층 배치, 다음 빈 장비 칸 및 겹치지 않는 새 대역 위치
- `src/lib/validate.ts`: 탭 단위 순수 검증
- `src/store/useProjectStore.ts`, `src/lib/projectValidation.ts`, `src/lib/projectStorage.ts`: 프로젝트 CRUD, 검증, 안전한 영속화
- `src/lib/export/`: PPTX, PNG/SVG, PDF

초기 구현: 다중 탭, 대역/장비/링크 편집, 계산기, CSV 가져오기, 문서 정보, 변경이력, 다중 형식 출력, JSON 백업/복원. 참고용 원본 HTML은 수정하지 않았습니다.
